# 🏙️ AI Civic Sentinel  
**Smart AI-Based Citizen Grievance & Action System**

AI Civic Sentinel is a modern, AI-powered civic issue reporting platform designed to help citizens report local infrastructure problems (such as potholes, broken streetlights, garbage, water leakage, etc.) with images and location data.  
The system intelligently analyzes issues, determines severity, and routes complaints to the appropriate authorities — enabling faster, transparent, and smarter civic governance.

---

## 🌐 Live Deployment

- **Frontend (Vercel)**  
  👉 https://ai-civic-sentinel.vercel.app/

- **Backend API (Render)**  
  👉 https://ai-civic-sentinel-backend.onrender.com/

---

## 🚀 Key Features

- 📸 **Image-Based Issue Reporting**  
  Citizens can upload real-world images of civic issues.

- 🤖 **AI-Powered Issue Detection**  
  AI analyzes uploaded images to identify the issue type automatically.

- ⚠️ **Severity Analysis**  
  Intelligent severity prediction (Low / Medium / High) for better prioritization.

- 🏢 **Auto Department Mapping**  
  Issues are mapped to the correct government department automatically.

- 📍 **Location & Evidence Support**  
  Every complaint is backed with image and geo-location data.

- 📊 **Transparent Tracking**  
  Ensures accountability and visibility in complaint resolution.
